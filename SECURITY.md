# Security Policy

## Reporting a Vulnerability

This service is not intended to be exposed to the internet. If you find something you think should be addressed, please report it privately via GitHub's vulnerability reporting: [Security advisories → Report a vulnerability](https://github.com/manbearwiz/youtube-dl-server/security/advisories/new).

## Deployment notes

- The app has no authentication, so it should only run on trusted networks.
- Dependabot alerts are enabled; pinned dependencies and the base image are kept current via automated updates.
